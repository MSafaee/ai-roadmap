
# HTTP-Request-Handler

A simple TypeScript CLI program that handles 5 request from the server concurrently using async programming. 
I used [{JSON} Placeholder](https://jsonplaceholder.typicode.com/posts) fake data to test my program.

## Requirements 

- Node.js v24.18.0
- pnpm v11.24.0

## Dependencies

- typescript v7.0.2
- @types/node v26.1.2

## Installation

```bash
pnpm install
```

## Run

```bash
pnpm exec tsc
node dist/index.js
```
